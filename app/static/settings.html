LightBurn-Anbindung

Fertige SVGs direkt an LightBurn 2.2 schicken. Der Schlüssel bleibt nur in diesem Browser – der Server speichert nichts.

Podman: host.containers.internal, Docker: host.docker.internal. Weitere Hosts über LIGHTBURN_HOSTS in compose.yaml.

Aus: Es gilt die Gruppier-Einstellung von LightBurn. Nur beim Importieren ins aktuelle Projekt.

Kein Schlüssel gespeichert.

Einrichtung

  1. In LightBurn 2.2: Einstellungen > Erweiterungen (Extensions) und „Allow API Access From Network“ einschalten. Nötig, weil der Container in der Podman-/Docker-VM läuft und nicht direkt auf dem PC.
  2. Einmalig koppeln: auf dem PC mit LightBurn tools\lightburn-pair.ps1 ausführen und den Dialog in LightBurn innerhalb von 30 Sekunden bestätigen (oder in LightBurn unter Manage API Security einen Eintrag wählen und Show Secret… – er braucht die Berechtigungen state und upload; ohne state schlagen „Verbindung testen“ und die Import-Bestätigung fehl). Den Schlüssel oben eintragen und speichern.
  3. Host wählen: Podman host.containers.internal, Docker host.docker.internal. Fragt die Windows-Firewall nach, LightBurn für private Netzwerke erlauben (eingehend TCP-Port 19520).
  4. Der Schlüssel bleibt nur in diesem Browser (als nicht auslesbarer WebCrypto-Schlüssel). Der Server speichert nichts; an ihn gehen nur Einmal-Token, die etwa eine Minute gültig sind. Die Einstellung gilt pro Browser und Adresse – localhost:8080 und 127.0.0.1:8080 zählen getrennt.
